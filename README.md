
# Tic-Tac-Toe

A classic Tic-Tac-Toe game built with vanilla JavaScript, HTML, and CSS — no frameworks, no libraries.

## About

This project was built to practice core JavaScript fundamentals: DOM manipulation, event delegation, game state management, and win/draw detection logic, without relying on any framework.

## Features

- Two-player gameplay (X and O) on a 3x3 grid
- Win detection across all 8 possible combinations (rows, columns, diagonals)
- Draw detection when the board is full
- Reset button to start a new game
- Turn indicator showing the current player

## Tech Stack

- JavaScript (ES6+)
- HTML5
- CSS3 (Grid layout)

## How to Run

1. Clone the repository
2. Open `index.html` in your browser

No build step or dependencies required.

## What I Learned

- Structuring game state as a data array separate from the DOM
- Using event delegation instead of individual listeners per cell
- Writing pure logic functions for win/draw detection
